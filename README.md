## Navratri Celebration Webpage

A festive, interactive Diwali website featuring traditional Indian-inspired visuals, warm colors, animated decorations and glowing diyas.

## Features
Festive hero section with a countdown timer
Animated decorative elements and glowing effects
Interactive cards highlighting Diwali celebrations
Clickable diyas with lighting effects
Celebration counter and greeting popup
Responsive layout for mobile and desktop
Reduced-motion accessibility support
## Technologies
HTML5
CSS3
JavaScript
Google Fonts
## Getting Started
Save the code in an index.html file.
Open the file in any modern web browser.
Enjoy the interactive Diwali celebration.
## Customization

Modify the CSS variables to change the color palette, adjust animations, or update the layout. JavaScript can be used to customize the countdown and interactive features.
